# DownloadsSorted - An automatic downloads files organizer

 The application keeps your Downloads folder tidy by automatically sorting files into appropriate subcategories.

---

## Features
* **Automatic Sorting:** Recognizes file types and moves them to dedicated folders (e.g., Documents, Images, Archives, etc.).
* **Simple Graphical User Interface (GUI):**
* **Lightweight and Fast:** Runs in the background without draining system resources.
* **Convenient Installer:** Easy installation via a dedicated setup wizard.

---

## System Requirements
* Operating System: **Windows 10 / 11** (x64)

---

## Download and Installation
1. Go to the **[Releases](../../releases)** tab in this repository.
2. Download the latest installer **`DownloadSorter.exe`**.
3. Run the file and follow the on-screen instructions.
